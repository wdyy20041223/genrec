## 3. 实际保留的算法

设`C(h,p)`是Train中最后一个完整历史SID为h、下一个商品SID前缀为p的计数。对每个深度投影下一SID；全局前缀概率使用加一平滑：

```text
P_global(p) = (C(p)+1) / (N_train + catalog_prefix_count[depth])
lift(h,p)   = log(1 + C(h,p) / (20 * P_global(p)))
bonus(H,p)  = sum_j 0.5^j * lift(history[-1-j], p),  j=0,1,2
score_d     = sum_{i<=d} log P_theta(token_i | H, own_prefix_<i)
              + alpha[d] * bonus(H,p)
alpha       = [0.0, 0.4, 0.4]
```

使用最近3个已观察完整SID。重复历史SID只计最近一次，但保留其实际时间距离权重；不足3个使用实际历史。每个深度都从**原始LM累计分数重新加该深度前缀奖励**，不会把D2奖励累积到D3。D1不修改评分。统计缺失时奖励为0。

最终层另对“用户已经见过、且SID只对应一个商品”的完整SID减1000分；碰撞组SID不屏蔽，避免看过某ASIN就把同SID的其他商品一起误删。此规则只使用推理历史和静态商品映射。Validation中121条目标SID曾出现在历史中，全部属于碰撞组，83条原版Top10命中也属于该组；这是数据诊断，不是按目标特判。

`score_d`是用于搜索/排序的校准能量，不能称作原模型Log Probability。另行保存的`raw_scores`始终等于各候选自身真实条件LogP之和；每项LogP≤0，所以原始累计LogP随深度不会增加。校准能量不要求满足这一单调性。

所有路径各自条件评分，共享一次Encoder并正确重排KV缓存；生成函数没有target参数。预测完成后才使用标签评价真实逐层保留Beam，绝不从最终路径反推早期存活。默认全15与显式全30使用同一套算法。

## 5. 迭代过程与未保留的方法

1. 首先完整复现原版全15/全30。64条真实预检验证父链、KV缓存和自身条件概率；发现FP16等分时`topk(30)`与`topk(256)`可能改变并列顺序，候选记录器因此保留实际选中TopK原序再追加额外候选。零调整、不同宽度和最终宽度不改Top10均通过检查。
2. 首轮在同一原版全30候选缓存上比较层权重、流行度、重复消费、历史相关性和最终分支多样性。发现历史条件转移比简单层重权重更有希望，随后集中探索其强度。
3. 分析重复消费过滤的误伤：碰撞SID不能视为一个已消费商品。修正为仅过滤单商品SID，随后把历史转移奖励用于D2选择而不只做最终排序，完整Validation继续提高。
4. 扩展到最近3个不同历史上下文，比较弱/强D2、D1额外校准、候选融合和合法性过滤。更强D2无Recall收益，D1额外仅多1条；融合没有收益，最终合法过滤只改变1条排名6→5。保留alpha=[0,.4,.4]和全15/全30两个成本档。锁定后只验证Test，不再调参。

| 方向 | 实际观察 | 决定 |
| --- | --- | --- |
| D1/D3层LogP重权重0.75或1.25 | 未同时超过原版全30的R10/N10 | 放弃 |
| 最终D1分支多样性惩罚0.2 | R10下降至8.9702% | 放弃 |
| 商品流行度−0.1 / +0.1 | 负系数有损，正系数仅小幅改善 | 由历史条件转移替代 |
| 只比较最近SID前缀是否相同 | 无稳定联合收益 | 放弃 |
| 按已见SID全部过滤 | 误伤83条原版命中，均为SID碰撞 | 改为仅单商品SID |
| 最后一项历史转移强度0.6/0.8 | 相较0.4无额外收益或下降 | 有限探索后停止 |
| 60–30–30原版搜索 | 比全30仅多1条命中，采集耗时105.48秒 | 放弃额外搜索成本 |
| D2校准0.8 | R10不变、N10略差 | 保留0.4 |
| D1额外0.2（全15） | 只多1条命中，提升太小 | 保留D1原分数 |
| 校准与原版搜索融合 | 同一评分下四项指标完全相同，但需两次推理 | 放弃 |
| 校准后合法完整SID过滤 | R10相同，仅1条从6→5，N10+0.000137pp | 放弃 |
| Sibling Rank Penalty | 仅通过独立参考实现的单元正确性检查，未做完整Validation效果实验 | 不声称测得效果 |

本轮49条Validation配置是基线、离线重排序、校准推理、消融和一致性对照的记录总数，**不是49次独立神经模型推理或49种新算法**。大部分参数共享同一候选缓存。完整Validation候选目录有11次神经推理和1次候选集合并，此外4次相同配置部署基准用于确认无记录器版本；没有为了凑数量重跑模型。

## 8. 建议保留与下一步依据

默认保留全15原行为；需要本轮新推理方法时，优先考虑**显式启用全15校准**：较全30校准快约14%，GPU内存约减半，Test仅少8条Top10命中。追求最高已测R10/N10时显式使用全30校准。两者均保留，并明确CPU查询带来的额外时间。

后续最有依据的方向是对稀疏转移计数的可靠性做更温和的平滑，以及减少CPU/GPU间逐批查询开销。主方法丢失的Test命中绝大多数仍在最终30，说明优先检查过强历史奖励导致的排序误提升；单纯继续扩大Beam或更强D2奖励证据不足。这里没有实施这些后续建议，也没有据Test调整参数；新方法应使用Validation或新的留出集再次选择。

本轮结论只适用于当前Beauty、固定权重与固定评价协议，不能视为其他数据集/检查点的普遍效果或对方法新颖性的证明。
